# 🏦 Banking Analysis Dashboard

## 📌 Problem Statement
This project aims to explore risk analytics in the banking and financial services sector. The goal is to understand how data can be used to minimize the risk of financial loss when lending to customers.

## 💡 Solution Overview
Using Power BI, we developed interactive dashboards that help banks make informed decisions based on client profiles. These dashboards assist in determining whether a loan applicant is likely to repay, enabling smarter loan approvals.

## 📊 Dataset Description
The dataset includes multiple interrelated tables:
- Banking Relationship
- Client-Banking
- Gender
- Investment Advisor
- Period

These tables are connected using primary and foreign keys, allowing for comprehensive analysis across client demographics and financial behavior.

## 🧹 Data Cleaning & Transformation
Key transformations performed:
- Created a column for client engagement timeframe.
- Calculated the number of days each client has been associated with the bank.
- Categorized estimated income into bands (Low, Mid).
- Derived processing fees based on fee structure.

## 📈 Key Metrics and KPIs
The dashboards track and visualize several important banking metrics:
- Total Clients
- Total Loan Amount
- Bank Loan and Business Lending
- Total Deposits (including savings, checking, and foreign currency accounts)
- Total Fees and Processing Charges
- Credit Card Balances
- Client Engagement Duration

## 📊 Dashboards & Visualizations
The Power BI report includes the following dashboards:
- Home Dashboard
- Loan Analysis
- Deposit Analysis
- Summary Dashboard

Each dashboard provides insights into client behavior, loan distribution, deposit trends, and overall banking performance.

## ✅ Conclusion
Power BI dashboards offer a powerful way to visualize and analyze banking operations. This project demonstrates how data-driven insights can support risk mitigation and strategic decision-making in the financial sector.
